# 品类规格库（format-skill）

通用规则：
- 印刷品一律 CMYK + 出血 3mm（横幅/喷绘例外见下）+ 安全边距 ≥5mm（大幅面 ≥50mm），文字距裁切线 ≥ 安全边距。
- 屏幕品一律 RGB / sRGB，尺寸给像素，不给 DPI 概念（导出 PNG 时 resolution 记 72/144 均可，像素数才是准的）。
- 像素换算：px = mm ÷ 25.4 × dpi。300dpi 时 1mm ≈ 11.81px。

## 印刷类
| 品类 | 成品尺寸 | 出血 | 分辨率 | 格式 |
|---|---|---|---|---|
| 海报（常规） | A3 297×420 / A2 420×594 / A1 594×841mm | 3mm | 300dpi（A1 可 200） | PSD / 印刷PDF |
| 海报（参赛/定制） | 按征稿要求逐字核对（如 600×900mm） | 按要求 | 按要求（常 300dpi） | PSD + JPG 双交 |
| 横幅/条幅 | 实测实量（如 12.2m×3.52m），短边方向像素按 72–150dpi 折算大图 | 无（或按厂方） | 大幅面 72–150dpi 即可 | JPG / PDF |
| 展板/展架 | 80×180cm 易拉宝 / 按展位实测 | 3–5mm | 150dpi | PSD / PDF |
| 名片 | 90×54mm | 3mm | 300dpi | PDF / AI |
| 画册/折页 | A4 210×285mm（骑马钉含书脊另算） | 3mm | 300dpi | PDF（逐页）/ AI |
| 包装盒 | 按刀版图展开尺寸 | 3mm | 300dpi | AI（刀线单独图层/专色） |

## 屏幕类
| 品类 | 尺寸(px) | 格式 |
|---|---|---|
| 小红书封面/配图 | 1242×1660（3:4）或 1242×1242 | PNG/JPG |
| 公众号封面 | 900×383（首图）/ 200×200（次图方图） | JPG/PNG |
| 抖音/视频封面 | 1080×1920（竖）/ 1920×1080（横） | PNG/JPG |
| 微博配图 | 1080×1080 起，长图 1080×任意 | JPG/PNG |
| PPT 演示 | 16:9（13.333×7.5in）默认；课程作业常 4:3 | PPTX（文字必须可编辑） |
| 作品集长图 | 宽 1500–1920，高度按内容 | PNG |

## 矢量类
| 品类 | 交付 | 要点 |
|---|---|---|
| Logo / 字标 | SVG 源 + .ai 导出（+ PNG 预览） | 路径化；字标若用字体文件字形，交付时转轮廓版另存一份 |
| 图标 | SVG 24×24 网格基准 | 描边转填充与否按使用方规范 |
| IP 形象 | SVG 源 + .ai | 分层命名（身体/表情/配饰分开） |

## PSD 图层规范
- 图层自下而上：背景 → 底图/照片 → 装饰 → 文案 → 印章/水印。
- 图层名用中文短名（背景/主体图/主标题/副标题/水印），改稿时按名定位。
- 文字层一律栅格化像素层（本机路线限制），图层名标注原文，方便在 PS 里照名重排为真文字层。
- 必须带真实 composite 预览（见 SKILL.md 铁律）。

## 交付核验清单（每次交付前逐项过）
1. 文件能被重新打开（PSD→psd-tools 读图层；PDF→pypdf 读页框；PPTX→python-pptx 读页数）。
2. 尺寸/页框与规格逐字对（mm 换算到 pt 误差 <1pt）。
3. 色彩模式对（印刷 CMYK、屏幕 RGB）。
4. 文件大小在对方上限内（如 ≤45MB），超了先压缩图层再交。
5. 源文件与导出文件成对留存（SVG 源 + .ai；job JSON + PSD）。
